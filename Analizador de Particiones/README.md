# Analizador de Particiones Pro

## ¿Qué es?
Es una herramienta avanzada de monitoreo diseñada para analizar de forma completa y profunda el estado del sistema, los discos y el hardware de la PC, todo presentado en una interfaz premium y moderna.

## Funciones Principales
- **Monitoreo de Discos**: Revisa la capacidad total, el espacio ocupado y el disponible en todas las particiones.
- **Inventario de Hardware**: Detecta y analiza el estado de componentes como la CPU, memoria RAM, red y otros dispositivos conectados.
- **Detección de Archivos y Rutas Pesadas**: Identifica qué carpetas y archivos están consumiendo más espacio de almacenamiento.
- **Gestor de Aplicaciones**: Lista el software instalado en el equipo junto con su versión y peso.
- **Exportación de Reportes**: Permite descargar toda la información escaneada en formato PDF para reportes técnicos.

_Nota: En este repositorio se encuentra disponible el archivo comprimido (ZIP) con la aplicación lista para ejecutar._
